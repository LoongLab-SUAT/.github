## 关于 LoongLab

**LoongLab** 是**深圳理工大学**的科研团队，由**李嘉龙老师**负责。我们围绕 **AI 基础设施中的网络创新**开展研究，关注计算机网络与分布式系统，重点探索光互联、可重构数据中心网络和算网资源协同。

我们的目标是面向新兴算力密集型应用，构建高性能、低功耗、强弹性的网络系统。

## 研究方向

| 方向 | 研究内容 |
| :--- | :--- |
| **数据中心网络** | 可重构数据中心网络的路由、传输协议与流量调度。 |
| **光通信网络** | 面向智算集群的光互联架构与快速光交换网络。 |
| **分布式通信** | 集合通信性能优化、分布式训练基础设施与跨域协同机制。 |
| **算网资源协同** | 网络、计算与存储资源的联合分配，以及边缘计算与 AI 赋能网络优化。 |

## 代表论文

以下为**李嘉龙老师及合作者**的代表成果，包含 LoongLab 成立前的研究工作。

- **Matryoshka: Realizing Hyperscale Data Center Network Design for the AI Era**  
  **USENIX NSDI 2026** · [论文与报告](https://www.usenix.org/conference/nsdi26/presentation/cai)  
  通过意图驱动和模型驱动的方法，将数据中心网络设计转化为交换机配置。

- **Unlocking Superior Performance in Reconfigurable Data Center Networks with Credit-Based Transport**  
  **ACM SIGCOMM 2025** · [论文](https://doi.org/10.1145/3718958.3754342)  
  面向可重构数据中心网络的基于信用的传输机制。

- **Unlocking Diversity of Fast-Switched Optical Data Center Networks With Unified Routing**  
  **IEEE Transactions on Networking, 2026** · [论文](https://doi.org/10.1109/TON.2025.3590083)  
  面向多类快速光交换数据中心网络的统一路由方法。

- **Uniform-Cost Multi-Path Routing for Reconfigurable Data Center Networks**  
  **ACM SIGCOMM 2024** · [论文](https://doi.org/10.1145/3651890.3672245)  
  面向可重构数据中心网络的统一成本多路径路由范式。
